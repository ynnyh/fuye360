## 谁会为此付钱

有三类人：律师、医生、财经博主（专业强表达弱）、实体店老板（要获客不会说）、做不到日更的中腰部博主（涨粉焦虑）。他们缺的不是观点，是「把观点变成 60 秒钩子」的手艺和时间。

## 一句话价值主张

「你对着镜头说，稿子、钩子、评论区我全包。」

## 工具链与成本

- **豆包/DeepSeek**：按「钩子-骨架-CTA」结构批量产稿；蹭热点时做选题快评。
- **Kimi**：读客户所在领域的长文章/报告，提炼成口播素材。
- **剪映**：顺手把稿子做成字幕版样片，交付物从「文档」升级成「半成品」。
- 启动成本：0 元。

## 开工步骤

1. **定一个垂类**：只接一类客户（如律师），把这类人的口播结构拆成 3 个万能骨架（争议开头/案例开头/清单开头）。
2. **建选题库**：用 AI 一次生成 100 条选题存进表格，这就是你谈单时甩出来的存货。
3. **免费产 3 条**：找目标客户的账号，挑一条旧视频「重写一版发给他」：「你这条播放量低不是内容不行，是前 3 秒开场挂了，我给你改了一版，念一遍试试。」
4. **接包月**：日更包（30 条/月）2000-3000，周更包 800-1200。交付物：脚本 + 分镜提示 + 评论区引导话术。
5. **半自动化**：把选题库和骨架做成固定 Prompt 链，单条脚本工时压到 15 分钟以内，剩下的时间就是利润。

## 获客与定价

- 获客动作就一个：去目标客户的评论区「以稿会友」，重写他们最差的一条视频开场。
- 加钱项：热点快评（2 小时加急 +50）、直播口播稿、账号人设定位报告（299 一次）。
- 律师医生类客单价可以到 300/条：他们一条视频带来的是案源。

## 风险与坑

- **专业内容别瞎编**：法条、医学、数据必须客户本人确认，你的稿子标注「供参考、需专业人士审定」——出事就是大事。
- 客户断更怪稿子：合同里写清「脚本交付 ≠ 播放量承诺」，保留「选题确认记录」。
- 别接 3 个以上垂类：脚本工厂的利润来自复用，垂类一多就变成纯代写。

## Prompt 模板

```text
你是一名口播短视频编导。人设与选题如下：
- 人设：{如：家事律师，懂心理学，专劝别急着离婚}
- 选题：{如：彩礼谈崩了怎么办}
- 时长：60秒（约180字）

按此结构写逐字稿：
1. 0-3秒钩子：一句让人停下手指的话（疑问/反常识/利益点，三选一）；
2. 3-45秒骨架：观点+1个具体案例或数字，口语句，禁止书面语；
3. 最后5秒CTA：引导关注或评论，设计一个具体的评论区问题；
4. 另给 3 个备选标题和 1 条置顶评论文案。
```
